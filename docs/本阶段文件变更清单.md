# 本阶段文件变更清单 (Phase 0 & Phase 1)

## 概述
本文件列出了在 Phase 0 (Data Source Audit) 和 Phase 1 (Core Metering Engine) 开发过程中在 `D:\实时Token监控工具` 项目内新建的所有文件与修改记录。

---

## 1. 新增工程与代码文件

- **项目根目录**:
  - `package.json`
  - `vite.config.ts`
  - `.gitignore`
- **Tauri / Rust 后端 (`src-tauri/`)**:
  - `Cargo.toml`: 配置 Rust 依赖 (`tauri`, `tokio`, `rusqlite`, `serde`, `chrono`, `uuid`, `parking_lot`, `sysinfo`, `tracing`)
  - `build.rs`: Tauri 构建脚本
  - `tauri.conf.json`: Tauri 2 悬浮窗配置
  - `icons/`: 应用图标库
  - `src/lib.rs`: Rust 库入口
  - `src/main.rs`: 二进制入口
  - `src/core/types.rs`: 全局 Token 事件、状态及能力 Schema
  - `src/core/normalization.rs`: Provider 语义归一化组件 (`UsageNormalizer`)
  - `src/core/correlation.rs`: 请求关联与置信度算法 (`RequestCorrelator`)
  - `src/core/baseline.rs`: 快照 Baseline 跟踪组件 (`BaselineTracker`)
  - `src/core/snapshot_accumulator.rs`: 累加快照流处理器 (`SnapshotAccumulator`)
  - `src/core/delta_calculator.rs`: 增量计算器 (`DeltaCalculator`)
  - `src/core/gap_detector.rs`: 时间空档与休眠检测器 (`GapDetector`)
  - `src/core/request_ledger.rs`: 权威请求账本与修正生成器 (`RequestLedgerManager`)
  - `src/core/reconciler.rs`: 跨 Adapter 去重重组器 (`CrossSourceReconciler`)
  - `src/core/tps_engine.rs`: 单调时钟 TPS 速度引擎 (`TPSEngine`)
  - `src/core/aggregator.rs`: 全局 Token Traffic 汇总器 (`GlobalAggregator`)
  - `src/core/persistence.rs`: SQLite WAL 事务持久化组件 (`StorageManager`)
  - `src/core/mock_adapter.rs`: 测试适配器 (`MockAdapter`)
  - `src/core/mod.rs`: 核心管线组装组件 (`EnginePipeline`)
  - `tests/p0_tests.rs`: 包含 Test A 至 Test R 的全套 P0 Ground Truth 测试套件

- **交付报告 (`docs/`)**:
  - `docs/Adapter-Capability-实测矩阵.md`
  - `docs/Core-Engine-实现报告.md`
  - `docs/P0-Ground-Truth-测试报告.md`
  - `docs/本阶段文件变更清单.md`
